# Traza Casa

App web instalable para propietarios que rentan propiedades: recibos de luz, agua y gas, inquilinos con alta y baja, pagos, avisos de renta por WhatsApp y un resumen que aprende de los gastos.

Este repositorio contiene **solo la app vacía**. No hay datos, claves, direcciones de backend ni código del servidor. Cada cliente tiene su propia hoja de Google y su propio script; la app se conecta a ellos con un enlace privado.

Para ver la demostración con datos de ejemplo, agrega `?demo` a la dirección.
